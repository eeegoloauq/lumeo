# Roadmap

## Next

- Trakt import and export
- Films you already have as a library
- Fix a file matched to the wrong title
- Anime specials sorted into their own tabs
- SOCKS5 proxy for torrent traffic
- Community translations
- A web demo to try without installing
- External player, subtitle outline and cache settings
- Typing in search with a gamepad
- Faster first open of a title
- Vertical episode list for series

## Later

- Management web UI for a remote core, later with playback
- HTTP and WebDAV sources
- Phone and TV apps
- Optional TMDB metadata with your own key
- Rotating home banner
- Copr, arm64, Flatpak and a signed Windows installer

## Not planned

- Switching servers without a restart: a rare, quick restart

Details and open questions: [design notes](design.md).
