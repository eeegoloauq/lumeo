
## Install

| System | File |
|---|---|
| Fedora | `.rpm`: `sudo dnf install ./lumeo-<version>-1.fc44.x86_64.rpm` |
| Arch | `.pkg.tar.zst`: `sudo pacman -U ./lumeo-<version>-1-x86_64.pkg.tar.zst` |
| Windows 10 and 11 | Setup `.exe`. It is not signed yet: in SmartScreen choose "More info", then "Run anyway" |
| Other Linux | `.tar.gz`: install your distribution's libmpv, unpack and run `lumeo.sh` |

`SHA256SUMS` lists the checksum of every file.
